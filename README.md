# Kể Chuyện Ngày Xưa · Stories from Long Ago

A one-page story recorder for a family elder. It shows one memory prompt at a time (Vietnamese first, English underneath) and records with one big red button.

- Recordings stay in the browser on that device until you tap **Save all to device**, which downloads a zip with the audio, a text file of the question for each recording, and `stories.json` (topic, question in both languages, date, length).
- Served by GitHub Pages from this `gh-pages` branch. The whole app is `index.html`.
